Deliverable 7 — Individual Reflection
CSE 1106 — Smart Classroom Comfort Monitor

1. What was your primary contribution to the project?

My main contribution was developing and testing the C program. I worked on temperature readings, calculating averages, displaying warnings, and saving the results. I also helped set up the program on the Raspberry Pi.

2. What was the most challenging technical problem your team encountered?

The biggest challenge was getting the program to work with the Raspberry Pi and the physical LED. We had to figure out the GPIO connections, install the correct libraries, and fix compilation errors.

3. How did your team use testing or debugging to solve a problem?

We tested different temperatures to make sure the program displayed the correct status. We also tested invalid inputs and checked the saved files. When we ran into errors on the Raspberry Pi, we used the terminal messages to find the problem.

4. Which skills from CSE 1106 were most useful?

The most useful skills were C programming, loops, conditional statements, functions, and debugging. We used these throughout the project to process temperatures and control the program’s output.

5. What would you improve if you had more time?

I would add a temperature sensor so the Raspberry Pi could automatically read the room temperature instead of requiring manual input. I would also improve the hardware setup and make the system easier to use.
